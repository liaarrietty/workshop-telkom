# 📡 Executive Financial & Subsidiary Tracker (Telkom Indonesia 2025)

Dashboard interaktif berbasis **Streamlit** dan **Plotly** untuk memantau kinerja keuangan konsolidasi TelkomGroup (2024 vs 2025), menganalisis kontribusi segmen bisnis, mendeteksi anomali pada anak perusahaan, serta mensimulasikan skenario perbaikan laba bersih.

## 📁 Struktur Proyek
- `app.py`: Aplikasi utama Streamlit (UI/UX, visualisasi Plotly, filter, dan simulator).
- `data_loader.py`: Modul pemuat dataset terstruktur kinerja konsolidasi, segmen bisnis, dan anak perusahaan.
- `requirements.txt`: Daftar dependensi Python.
- `README.md`: Panduan instalasi dan penggunaan.
